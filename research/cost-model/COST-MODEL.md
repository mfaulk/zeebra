# Cost model: predicted against measured, with the difference attributed

Generated by `cargo run --release --example cost_model`. Do not edit: regenerate it.

Every figure carries a **basis** — `measured`, `fitted`, `predicted` or `extrapolated` — because the failure this register exists to prevent is a prediction quoted with the confidence of a measurement. A `measured` column holds only what an instrument read; a row reporting an estimate there is a schema error and does not load. **Peak allocated and peak resident are separate columns** and are not comparable. Prediction error is computed from the predicted and measured columns and is never authored. The history is **append-only**: a re-measurement is a new row with a new commit, never an edit.
