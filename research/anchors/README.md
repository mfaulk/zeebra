# Published external anchors

These records identify external sources; they are not local performance measurements and do not
belong to the competitive scoreboard.

[`steel-dense-f4-provenance.json`](steel-dense-f4-provenance.json) records the retrieval date,
checkout commit, HTTP responses and content hashes for the primary sources used in the
[dense-F4 study](../../docs/research/classical-benchmarks.md#24-441-the-dense-f4-ladder-and-the-conversion-stage-caution).
Source pages and PDFs are not vendored. Re-fetch the recorded URLs to check current availability;
content changes may change their hashes without invalidating the historical access record.
